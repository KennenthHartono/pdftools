    ABOUT

    Simple tools. Local processing.

    DOCUMENT // LAB is a small collection of document utilities that run entirely as a static web page. There is no server behind it, so there is nothing to sign up for and nothing to wait in line for.

    It is honest about its limits. Word → PDF is done by a built-in converter that approximates the layout rather than reproducing Word exactly, and the lossy compression modes say so before you use them.

    Built with plain HTML, CSS and JavaScript, plus the open-source libraries pdf-lib, PDF.js and fflate. Source code. Designed and built by Kennenth.

    PRIVACY

    Your files never leave your device.

    • Files are opened and processed in your browser's memory.
    • No automatic uploads. Document contents are not sent to any service.
    • No account, no login, no analytics, no tracking scripts.
    • Nothing is stored permanently. The only thing saved on your device is your light/dark theme choice.
    • All code, fonts and libraries are served from this site, not from third-party CDNs.
